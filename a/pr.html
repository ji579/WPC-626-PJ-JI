쿠사마야요이
반응형 사이트 리뉴얼

작가의 아이덴티티를 웹사이트 전반에 담아내기 위해, 분리되어 있던 작가 페이지와 미술관 페이지를 하나의 플랫폼으로 통합한 퍼블리싱 프로젝트입니다. 사용자가 작품 정보와 전시 콘텐츠를 보다 직관적으로 탐색할 수 있도록 UI 구조를 개선했습니다.

- PC / Tablet / Mobile 반응형 제작 - 브랜드 스타일을 반영한 색감·패턴·모션 구현 - 코드 구조화 및 UI 컴포넌트화로 유지보수성 향상 - 레이아웃 재구성 및 사용자 흐름 개선

사용 툴 :
HTML5 CSS3 JavaScript jQuery
사용 기술 :
Git/GitHub Visual Studio Code Figma Photoshop Illustrator

Website Figma Github PDF
About this project
배경

웹 퍼블리셔 과정을 듣기 전, 쿠사마 야요이 작가의 전시회를 찾아보면서 공식 웹사이트를 이용한 적이 있었습니다. 그때 느꼈던 불편함들이 계속 기억에 남아, 이를 직접 개선해보고 싶다는 생각으로 해당 웹페이지를 선정했습니다.

문제점

기존 사이트는 테이블 레이아웃 기반의 구식 디자인과 낮은 가독성이 문제였습니다. 특히 작가 사이트와 미술관 사이트가 분리되어 있어 정보 접근성이 떨어졌고, 모바일에서는 레이아웃이 무너지는 문제도 있었습니다.

해결 방향

분리된 세 사이트를 하나의 플랫폼으로 통합하고, CSS Grid·Flexbox 기반으로 전면 재설계했습니다. 쿠사마 야요이 작품의 시각적 아이덴티티를 웹에 반영하면서, 사용자 동선을 중심으로 정보 구조를 재편했습니다.
