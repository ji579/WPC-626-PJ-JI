## 💻 주요 코드 구현 설명

### 1. 📱 반응형 네비게이션 (Glassmorphism)
```css
nav {
  position: fixed;
  top: 0;
  background: rgba(255, 255, 255, 0.1);
  backdrop-filter: blur(20px);  /* 유리 효과 */
  padding: 1.8rem 6%;
  z-index: 99;
  border-bottom: 1px solid rgba(139, 115, 85, 0.2);
}
```
- `backdrop-filter: blur(20px)` - 배경을 흐리게 하여 현대적인 글래스모피즘 효과
- `position: fixed` - 스크롤 시에도 상단에 고정
- 반투명 배경으로 콘텐츠 위에 자연스럽게 오버레이

---

### 2. ✨ 텍스트 애니메이션 (성장하는 ↔ 노력하는)
```css
.changing-text::after {
  content: "성장하는";
  animation: textChange 8s ease-in-out infinite;
}

@keyframes textChange {
  0%, 45% { content: "성장하는"; }
  50%, 95% { content: "노력하는"; }
  100% { content: "성장하는"; }
}
```
- CSS `content` 속성을 이용한 텍스트 자동 변경
- 8초 주기로 "성장하는" ↔ "노력하는" 반복
- 하단 언더라인도 함께 애니메이션 효과 추가

### 4. 🎨 3D Tilt 효과 (Skill Cards)
```javascript
document.querySelectorAll(".tilt").forEach((el) => {
  el.addEventListener("mousemove", (e) => {
    const rect = el.getBoundingClientRect();
    const x = e.clientX - rect.left;
    const y = e.clientY - rect.top;

    const centerX = rect.width / 2;
    const centerY = rect.height / 2;

    const rotateX = (y - centerY) / 10;
    const rotateY = (centerX - x) / 10;

    el.style.transform = `perspective(1000px) rotateX(${rotateX}deg) rotateY(${rotateY}deg)`;
  });
});
```
- 마우스 위치에 따라 카드가 3D로 기울어지는 효과
- `perspective`로 원근감 부여
- `rotateX`, `rotateY`로 입체적인 움직임 구현

---

### 5. 🎬 가로 스크롤 포트폴리오 (Horizontal Scroll)
```javascript
function updateHorizontalScroll() {
  const rect = portplioSpacer.getBoundingClientRect();
  const progress = Math.abs(rect.top) / (portplioSpacer.offsetHeight - window.innerHeight);
  const maxScroll = portplioTrack.scrollWidth - window.innerWidth;

  portplioTrack.style.transform = `translateX(${-progress * maxScroll}px)`;
}

window.addEventListener("scroll", updateHorizontalScroll);
```
- 세로 스크롤을 감지하여 가로로 콘텐츠 이동
- `progress` 값으로 스크롤 진행도 계산
- `sticky` 포지션과 `transform`으로 부드러운 가로 스크롤 효과

### 6. 🎯 모달 시스템 (프로젝트 상세보기)
```javascript
document.querySelectorAll(".portplio-card").forEach((card) => {
  card.addEventListener("click", function () {
    const projectId = this.closest(".portplio-item").getAttribute("data-project");
    const project = projects[projectId];

    // 모달에 프로젝트 정보 삽입
    document.getElementById("modalTitle").textContent = project.title;
    document.getElementById("modalDescription").textContent = project.description;
    
    // 모달 표시
    document.getElementById("projectModal").classList.add("active");
    document.body.style.overflow = "hidden";  // 배경 스크롤 방지
  });
});
```
- 각 프로젝트 카드 클릭 시 해당 프로젝트 정보를 모달에 표시
- `data-project` 속성으로 프로젝트 ID 매핑
- 객체 리터럴로 프로젝트 데이터 관리

### 7. 📋 클립보드 복사 (이메일 복사 기능)
```javascript
function copyEmail() {
  const email = "jiheene00@naver.com";
  
  navigator.clipboard.writeText(email)
    .then(() => {
      showCopyNotification();  // 복사 성공 알림
    })
    .catch((err) => {
      fallbackCopyEmail(email);  // 구형 브라우저 대응
    });
}

function showCopyNotification() {
  const notification = document.createElement("div");
  notification.className = "email-copied";
  notification.textContent = "이메일이 복사되었습니다! ✓";
  document.body.appendChild(notification);
  
  setTimeout(() => notification.classList.add("show"), 10);
  setTimeout(() => notification.remove(), 2300);
}
```
- 최신 Clipboard API 사용 (브라우저 호환성 우수)
- 복사 성공 시 알림 메시지 표시
- 구형 브라우저를 위한 폴백 메서드 제공

### 8. 🎪 호버 오버레이 효과 (프로젝트 카드)
```css
.portplio-overlay {
  position: absolute;
  inset: 0;
  background: linear-gradient(135deg, rgba(139, 115, 85, 0.95), rgba(196, 181, 160, 0.95));
  opacity: 0;
  transition: opacity 0.5s ease;
  display: flex;
  flex-direction: column;
  justify-content: flex-end;
  padding: 3rem;
}

.portplio-item:hover .portplio-overlay {
  opacity: 1;
}
```
- 카드 호버 시 그라디언트 오버레이가 부드럽게 나타남
- `inset: 0`으로 부모 요소 전체를 덮음
- `flex`로 콘텐츠를 하단에 정렬

### 9. 📐 반응형 미디어 쿼리
```css
@media (max-width: 1024px) {
  .hero-content {
    flex-direction: column;  /* 세로 배치로 변경 */
  }
  .hero h1 {
    font-size: 3.5rem;  /* 폰트 크기 축소 */
  }
}

@media (max-width: 768px) {
  .skills-container {
    grid-template-columns: 1fr;  /* 1열 레이아웃 */
  }
  .portplio-item {
    flex: 0 0 290px;  /* 카드 크기 조정 */
  }
}

@media (max-width: 480px) {
  .hero h1 {
    font-size: 2.2rem;
  }
  .spani4 {
    animation: none;  /* 모바일에서 애니메이션 비활성화 */
  }
}
```
- 3단계 브레이크포인트: 1024px, 768px, 480px
- 각 디바이스에 최적화된 레이아웃 제공
- 모바일에서는 성능을 위해 일부 애니메이션 제거
